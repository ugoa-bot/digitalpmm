# SEO setup

Implemented in this build:
- Unique title and meta description per page
- Canonical URLs
- Open Graph and Twitter metadata
- One H1 per main page
- Structured data
- XML sitemap at https://digitalpmm.vercel.app/sitemap.xml
- robots.txt
- Custom 404 page
- Extensionless service URLs through Vercel rewrites
- Internal links between service and project pages
- Mobile-responsive existing layout retained
- HTTPS is provided by Vercel

## Google Search Console and Google Analytics
The website is prepared for these services, but actual account/property connection and sitemap submission require the Google account/property IDs. No IDs were supplied, so no verification code or Analytics measurement ID has been invented.

After deployment, add the site to Google Search Console and submit `https://digitalpmm.vercel.app/sitemap.xml`. Add the Google Analytics measurement ID to the site's analytics configuration when available.
